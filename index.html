Course Overview

An Operating System manages computer hardware and software resources and provides services for application programs. This course introduces OS structure, process management, CPU scheduling, synchronization, deadlocks, memory and virtual memory, file systems, secondary storage, protection and security.

Course Outcomes

By the end of the course, students should be able to:

CO1 · Understand

Explain fundamental operating-system concepts, architecture, services and functions.

CO2 · Apply / Analyze

Apply and compare CPU scheduling algorithms and explain synchronization mechanisms.

CO3 · Analyze

Analyze deadlock conditions and select suitable prevention, avoidance, detection or recovery strategies.

CO4 · Analyze

Compare paging, segmentation, demand paging and page-replacement approaches.

CO5 · Apply

Explain file-system and storage-management mechanisms and demonstrate basic Linux file and permission administration in a safe lab.

Unit-wise Syllabus

Unit I — Introduction & System Structures

Role and definition of an OS; computer-system operation; storage structure; OS structure and operations; system architectures; multiprogramming and multitasking; process, memory, storage, protection and security; system calls, system programs and system boot.

Unit II — Processes, Scheduling & Deadlocks

Process concepts and scheduling; process operations; IPC; client/server communication; FCFS, SJF, Priority and Round Robin; critical-section problem, Peterson’s solution, synchronization, Dining Philosophers, monitors; deadlock characterization, prevention, avoidance, detection and recovery.

Unit III — Memory & Storage Management

Swapping, contiguous allocation, paging, page tables, segmentation; demand paging, copy-on-write, page replacement, frame allocation, thrashing, memory-mapped files, kernel memory; file concepts, access methods, directories, mounting, sharing and protection.

Unit IV — File Systems & Secondary Storage

File-system structure and implementation; directory implementation; allocation methods; free-space management; efficiency, performance, recovery, log-structured file systems and NFS; mass storage, disks, disk attachment, RAID, stable storage and tertiary storage.

Unit V — Protection & Security

Protection goals and principles; domains, access matrix, access-control implementation and revocation; security problems, program and network threats, cryptography, authentication, security defences, firewalls and Linux case study.

Experiential Learning Case: Campus Server Slowdown

Scenario: During course registration, a campus server becomes slow. Several processes compete for CPU time, memory use rises, and one process waits for a resource held by another. Students report delayed responses.

Team task

  1. Identify what evidence should be collected before changing system settings.
  2. Explain how waiting time and turnaround time differ.
  3. Compare how FCFS and Round Robin may affect responsiveness.
  4. Explain the four necessary deadlock conditions and one prevention strategy.
  5. Suggest safe checks for memory pressure, storage and file permissions.

Deliverable and rubric

Submit a one-page incident report with the diagnosis, two possible solutions, the selected action, risks and reflection. Suggested 20-mark rubric: concept accuracy (5), evidence/calculations (5), comparison (4), feasibility and safety (3), communication and reflection (3).
